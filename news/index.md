# Changelog

## shinydataviewer 0.2.0

CRAN release: 2026-08-05

- Add support for datetimes
- Add ‘hms’ to Suggests
- Add ‘spelling’ to Suggests
- Add new example that lets user upload data
- Fix bug when categorical column is completely missing
- Add bslib dark mode compatibility
- Fix transparent backgrounds between card elements when in fullscreen
  mode
- Add `plot_color` parameter to change color of sidebar plots
- Add example for
  [`summarize_columns()`](https://ryan-w-harrison.github.io/shinydataviewer/reference/summarize_columns.md)
